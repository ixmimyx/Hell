# HELL

موقع Horror من صفحتين، HTML و CSS و JavaScript عادي من غير أي تنصيب.

## الملفات

| الملف | إيه اللي فيه |
|---|---|
| `index.html` | الصفحة الأولى: صورة البنت + كلمة HELL بتتكتب حرف حرف + زرار Hell Here |
| `inside.html` | صفحة البروفايل: الصورة والاسم، أيقونات السوشيال، شبكة الصور المصغرة، مشغل الأغنية، وسويتش أبيض وأسود |
| `assets/` | الصور (demon.jpg و g1–g5)، الأغنية (song.mp3)، وخط HELL (HorrorVision.ttf) |
| `README.md` | الملف ده |

## تشغيل الموقع على جهازك

دوس دبل كليك على `index.html`، وهيفتح في المتصفح. مفيش أي حاجة تتحمّل أو تتنصب.

## الرفع على GitHub من غير أوامر

الرفع بيشمل كل حاجة: الصفحتين + فولدر `assets` كامل جواه الأغنية `song.mp3` والصور والخط.

1. افتح [github.com](https://github.com) واعمل حساب لو مفيش.
2. من فوق على اليمين: **+** ← **New repository**.
3. الاسم مثلًا `hell`، اختار **Public**، ودوس **Create repository**.
4. في الصفحة اللي هتفتح اختار **uploading an existing file**.
5. اسحب الملفات دي وارميها في الصفحة: `index.html` و `inside.html` و `README.md` و **فولدر `assets` بالكامل** (اسحب الفولدر نفسه، GitHub بيحفظ اسمه جواه).
6. دوس **Commit changes**.

مهم: اسم فولدر `assets` وأسماء الملفات جواه زي ما هي بالظبط، لأن الصفحات بتنادي عليها بالأسماء دي (`assets/song.mp3` و `assets/demon.jpg` … إلخ). لو الاسم اتغير الأغنية والصور مش هتظهر.

## تشغيله كموقع على GitHub Pages

1. في المستودع: **Settings** ← **Pages**.
2. تحت **Source** اختار **Deploy from a branch**.
3. **Branch**: `main` و **Folder**: `/ (root)` ← **Save**.
4. استنى دقيقة، واللينك هيبقى: `https://اسم-حسابك.github.io/hell/`

بعد كده صفحة البروفايل تبقى على `https://اسم-حسابك.github.io/hell/inside.html`.
